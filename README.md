# 画像フォルダ

ホームページで使う写真やロゴは、この `images` フォルダに入れてください。

## よく使う画像名

- `hero.jpg`：トップページのメイン画像
- `top-business.jpg`：トップページの事業内容カード
- `top-works.jpg`：トップページの施工実績カード
- `top-recruit.jpg`：トップページの採用情報カード
- `top-company.jpg`：トップページの会社概要カード
- `strength.jpg`：トップページの強み写真
- `business-hero.jpg`：事業内容ページのメイン画像
- `business-tech.jpg`：事業内容ページの技術説明写真
- `works-hero.jpg`：施工実績ページのメイン画像
- `works-01.jpg`：施工実績1の写真
- `works-02.jpg`：施工実績2の写真
- `works-03.jpg`：施工実績3の写真
- `recruit-hero.jpg`：採用情報ページのメイン画像
- `recruit-message.jpg`：採用情報ページのスタッフ写真
- `company-hero.jpg`：会社概要ページのメイン画像
- `og-image.jpg`：SNSやチャットでURLを共有した時に表示される画像
- `daito-logo.png`：ホームページ内で使う正式ロゴ

## 新しい画像を使う場合

1. このフォルダに画像を入れます。
2. `かんたん編集.html` を開きます。
3. 「画像」の「登録済み画像一覧」に `images/ファイル名.jpg` の形で1行追加します。
4. 各画像の選択欄で、その画像を選びます。
5. `データを更新` を押して、`site-data.js` を更新します。
